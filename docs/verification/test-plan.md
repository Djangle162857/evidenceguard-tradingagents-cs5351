状态：测试方案已获用户启动执行授权；具体测试源码未记录逐件预批准。现已生成并执行部分离线测试，实际数量见progress及checkpoint；目录规格不能当作执行结果。后续具体代码和测试hash仍待真实人审，不能补造实现前时序。新增或修改测试不得沿用不存在的批准。

## 数据与接口

以[接口契约](../architecture/interface-contracts.md)为独立oracle；测试不得导入实现私有常量作为预期答案。时钟、provider和数据源采用显式fixture/stub，离线禁止网络。测试fixture的人工批准不等于产品真实审批。

fixture时间基准固定`2026-11-18T22:00:00Z`，合法截点`2026-11-18T21:00:00Z`；有效行情available_at和新闻published_at早于截点，采集时间单独保存。测试不依赖系统当前时间。

## 外部传输与OpenCode预检

零费用mock须捕获实际请求：模型名保留`CS5351/DeepSeek-V4-Flash`完整字符串；输出限制生效；工具权限、禁止读凭据、禁止写Human-only文件、禁shell/MCP/其他provider实际拒绝。仅看到配置文件不算通过。

准备阶段生成请求最多12次，费用上限1美元，计入开发分账。传输在任何请求前预留，USD使用整数微美元；未知用量保留预留并停止。费用上界先按网关公布的完整输入/输出能力计算，不把OpenCode steps或仅step_finish当硬限。禁止自动SDK重试、跳转到其他域名和日志输出认证头。

## 正式评估协议

固定AAPL/MSFT/NVDA三个任务，使用yfinance可取得的当期共同快照，快照采集完成时确定UTC截点。先排除时间未知/未来证据，再冻结hash。两组模型、数据、基础分析师和轮次相同；候选结构和预算变化是研究差异。

两次重复，顺序预登记为AAPL:B/C,C/B；MSFT:C/B,B/C；NVDA:B/C,C/B。两组独立运行目录、无跨run记忆、无完成缓存。baseline不能仅因没有新卡片schema被判失败，采用共同事实、时间和实用性标准。

每个重要事实标supported/unsupported/unverifiable，后两者不算支持。唯一学生对匿名化报告进行第一轮标注，至少24小时后逐项复核，保存前后标签、理由和证据；披露结构差异可能暴露组别，不称完全盲法。AI标签只是辅助。

可用条件：completed、有≥1重要事实、支持率≥0.95、五项各1分rubric≥4/5；候选另须gate passed。六次候选至少5次可用，成功数不少于baseline。全部失败进分母；未知usage使成本结果不可判定。20% token节省为Should，不以删样本或放宽质量换取。

## 回归、变更与证据

每轮运行全部上游历史离线测试和项目离线测试；需要API的历史/live测试由本机受控运行，CI核验与当前版本hash绑定的证据，公开仓库不放课程密钥。prompt/model变化必须生成新的固定集重放证据，不复用旧结果。

每份结果包括版本、测试/fixture hash、命令、退出码、运行时间、通过/失败和限制。框架加载失败、未实现或未运行不能标为通过。必要修订通过新ADR和真实人审后继续。
