# ADR-005：评估汇总与课程 CI 检查

日期：2026-11-19。状态：增量实现及离线验证中；当前源码人审与正式实验仍待进行。

## 决策

FR-006 的计划/执行记录与人工质量标注分开保存。`quality.prepare_annotations`只生成空白模板，不生成事实标签、评分、学生身份或复核时间。`summarize_quality`绑定plan hash、全部12行和各产物hash，从学生填写的事实与rubric计算指标。

支持率以所有重要事实为分母，unsupported和unverifiable都不算supported。可用结果必须完成、支持率至少0.95、rubric至少4/5；候选另须验证通过。候选至少5/6可用且成功数不少于baseline。baseline缺少候选卡片schema不能单独判为语义失败。未完成/失败行一直保留；缺少用量或仍有预留时token节省为未知，不补零。

学生标注和至少24小时后的复核是实际人类行动。程序检查字段、hash和时间间隔，无法证明签名者身份、标签事实正确或复核确实独立完成；报告不得作这些额外声明。单人复核不是第二位独立标注者。

## 六项检查

新增workflow并保留上游CI。六项固定名称为test-approval、static-analysis、requirements-schema、semantic-evaluation、regression、ai-use-log。全部在无课程密钥、无模型调用的环境运行；不允许continue-on-error或缺失证据时自动通过。

审批检查要求真实批准记录绑定当前完整审查清单的文件字节hash，并逐文件核对源码、测试、规则和workflow；agent不代填批准。它核验已记录的授权绑定，不能补成过去未发生的实现前预批准。语义检查读取实际冻结计划、全部结果、产物和人工标注；缺少正式数据时保持失败。

本地检查通过只证明相应程序行为。实际GitHub运行、失败/修复、required checks与分支保护还须在真实仓库验证，不能因workflow文件存在就标为完成。

## 保留的限制

当前rules.md按用户明确委托由Codex代建，该来源已经披露；文件存在不等于满足课程Human-only独立撰写要求。精确源码审批尚缺，不能自动制造。原始临时会话目录因本机重启丢失；六份已导出的公开会话、源码hash和累计费用账本幸存，后续会话立即归档至持久私有目录。缺失原始材料不补造。
