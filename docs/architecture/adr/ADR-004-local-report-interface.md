# ADR-004：本地报告前端

日期：2026-11-19。来源：用户要求设计前端界面并提供效果图。

第一版增加位于 `src/evidenceguard/web/` 的静态中文研究工作台，复用现有 DecisionArtifact JSON。浏览器展示研究总览、证据台账、论点卡片和运行详情；支持本地选择报告、筛选证据、下载原始 JSON。使用系统字体、原生 HTML/CSS/JavaScript，无额外前端依赖或远程资源。

演示数据由现有离线 replay 入口生成，保留合成数据标记及 completed/passed/pending/draft 原始状态。页面中的状态是报告记录的展示，不构成重新门禁、真实人审或发布。第一版不添加模型调用、交易能力、服务端上传或审批端点；现有 CLI 继续承担业务执行。

本地预览使用 Python 标准库静态服务器，仅绑定 127.0.0.1，服务目录限定为上述静态资源目录。报告导入在浏览器内完成。界面中的来源链接仅允许 HTTP/HTTPS，报告与证据文本作为文本呈现。

应用源码经现有本地 OpenCode + CityU `CS5351/DeepSeek-V4-Flash` 请求级预算边界生成并原样捕获。Codex 负责设计规格、审查、运行、截图与记录。页面批准状态仍为待真实人审，本 ADR 不补记任何人工批准。

验证包括桌面和手机布局、真实合成报告加载、导航、证据筛选、报告导入及历史离线回归。实际结果另见 `docs/verification/frontend-review.md`；截图不能作为在线实验或语义质量证据。


## 追加决定：鲜明配色与公开行情面板

来源：同一用户继续要求更明显的配色，并明确要求真实股票的常用图表类型和多个时间范围。原本仅用于布局的合成 SVG 不能满足这个需求，因此改为独立的 TradingView 公开行情 iframe；报告仍复用本地 DecisionArtifact。参考页面为 moomoo 的 AAPL 页面、Webull 的 AAPL 报价页面和 TradingView 官方 Advanced Chart 文档。采用深蓝侧栏、白色卡片、鲜橙操作与绿色/琥珀色状态，研究摘要移到图表旁。

行情组件只接收 AAPL/MSFT/NVDA 的固定公开证券代码及允许的图表类型、周期、范围。外部组件使用独立来源的 iframe，不在本地页执行供应商脚本；设置 no-referrer，并限制 sandbox 为 scripts/same-origin，不授予表单、弹窗或顶层导航。没有把报告、证据、论点、运行 ID、hash、凭据或用户导入内容写入图表地址，也没有增加账户、交易、审批、模型或后端上传端点。

外部行情需要联网，行情源可延迟或不可用，其价格与当前报告的历史截点无绑定关系，不能作为报告新增证据或预测结果。页面保留来源署名、延迟提示、重新加载与关闭在线行情；关闭后不以合成价格代替真实行情。报告查看、筛选与下载仍在本机完成。此项决定取代第一版“无远程资源”的页面设计约束，不改变确定性门禁、预算或发布状态规则；本记录不构成产物的人审批准。

图表类型和区间的实际可用范围以组件提供的数据为准。UI 验证在本地页面进行；公开行情显示不计入模型业务评估，也不作为正式回测数据。


## 追加决定：深色金融终端与动态预测对照

用户最新明确选择深色，并要求历史和预测同时具备交互及自动更新。此次参考 GitHub 的 daily_stock_analysis、FinceptTerminal 和 FinGPT 官方 UI 截图/演示，采用炭黑底、橙色选中/操作、蓝色历史、橙色预测虚线、紫色区间；参考记录见 `docs/design/frontend-references.md`。此决定取代上段白色卡片配色。未复制第三方项目代码或品牌资源。

真实行情保留六种常用图形、九档周期和八档范围。范围按钮按供应商实际聚合周期同步下拉框，单独选周期时移除 range，防止供应商覆盖导致标签不一致。外部行情与本地报告保持独立。

新增“预测对照”视图，以原生 Canvas 展示独立文件中的历史、预测与区间，提供十字线读数、范围/点数、播放/暂停/重播和进度控制。每五秒读取本地 forecast.json，可更新历史与预测；不会调用模型。现有后端没有输出预测价格序列，因此附带数据均明确标为合成界面演示。文件契约见 `frontend-forecast-data.md`，不能把演示曲线称为真实预测。没有改变业务hash、门禁、预算、审批或发布端点。
