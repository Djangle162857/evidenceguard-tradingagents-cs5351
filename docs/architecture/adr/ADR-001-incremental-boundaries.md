# ADR-001：复用上游并集中安全权威

日期：2026-11-19。状态：proposed；human approval：pending。

## 背景和选择

基线已有多角色、结构化输出、自由文本回退、日期保护、checkpoint和token统计。单人六天内保留7FR，需要集中增量而非重写。

选择保留上游目录和测试，新增独立EvidenceGuard包及三个适配点。最后的发布状态由确定性gate和人工hash批准共同控制，LLM和上游报告导出都无权绕过。

候选：全量重写（集成和回归成本过大）；只改prompt（无独立权威和原子预算）；集中增量（选中，测试边界清楚但须穷尽调用与输出入口）。不声称没有检查过的上游路径已安全。

## 上下文与成本

应用上下文按不可变规则/运行契约、当前任务、合资格证据摘要、卡片和冲突、必要历史分层。事实和证据ID不因压缩丢失；不传无限增长的完整辩论。单调用输入上限8,000、输出1,024，输入估计达到6,000时确定性缩减重复历史；若仍超额则停止，不能删除关键规则。

编码任务一次一个边界模块，附批准需求和测试。上下文缩减后重新注入规则、需求ID、权限、接口、预算和退出条件。开发阶段优先禁止后台压缩；若启用压缩，其调用也经relay计费。

## 后果和重新决策条件

需要覆盖structured、plain、tool、sync/async、失败和辅助调用；callback统计不是预算控制。若发现未包裹入口、输出绕过、原生限制未生效，停止受影响运行并补ADR/测试/人审。修改端点、时间资格、预算权威或发布hash规则均属安全关键变更。
