# ADR-002：源码生成与首批边界闭环

日期2026-11-19；Codex记录，具体安全代码人工审阅待进行。依据execution-authorization.md启动增量实现。

本轮保留上游212个原始文件，校验原文hash后存为本地Git基线4419f12。新增EvidenceGuard位于src，课程测试位于test/offline。尚未改动上游研究/风险链路；离线回放不作为真实业务或对照实验。

代码和测试由本地OpenCode的课程模型生成。原生文件写入权限问题后，采用真实JSON事件中的完整Python文本原样捕获；不把Codex写作当成DeepSeek源码。大文件替换曾触发输出截断和三次完整重试，全部费用保留；之后小改采用OpenCode生成的精确匹配补丁脚本，Codex检查其路径和变更后执行。修复后的最终hash另行保存，不能把补丁后的源码称为最初生成文件的原始hash。

测试首版也出现错误字段、非法零预留和假循环图夹具，均明确返还OpenCode修正。具体测试源码未获事前逐件人审；不声称满足了尚无证据的批准时序。不会通过虚构Human-only规则或批准记录补齐。

首批职责：纯配置契约、证据资格、卡片图、独立门禁、SQLite原子预留和结算、当前业务hash的人审发布、离线回放和CLI。预算未知用量保留预留，停止不妨碍其他已发请求结算。发布重建证据并重新门禁；不信任文件自报passed。合成审阅仅在测试存储中存在。

剩余：真正接入上游五个角色和行情/新闻快照、覆盖实际HTTP调用、真实pilot/12次评估、GitHub六项检查和保护、人工语义标注及交付材料。未实现的内容不标为通过。
