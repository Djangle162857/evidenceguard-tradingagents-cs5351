# Risk list

| 风险 | 影响 | 应对/触发 |
|---|---|---|
| 课程限流或网关故障 | 延迟、失败 | 串行和显式有限重试；保留失败，不换个人API |
| OpenCode无原生成本上限 | 辅助请求漏账 | 共享relay逐HTTP请求预留；事件只核对 |
| 使用量语义或上限不可信 | 无法保证预算 | 停止付费调用，核账；不将未知当零 |
| 新闻缺少时间或覆盖 | 事实不可评估 | 当期冻结快照，隔离未知项，不造历史数据 |
| 回退/旧导出绕过门禁 | 非法发布 | 集中最终权威，测试各输出入口 |
| 单人标注偏差、小样本 | 结论过强 | 隐藏组别、24小时复核、披露有限盲法和描述性结论 |
| 截止近、7FR与治理并行 | 交付不完整 | 先闭环、复用上游、无Web UI，逐项报告完成状态 |
| 公开仓库泄露私人材料 | 凭据或个人信息暴露 | 私有附件分离、脱敏、发布清单复核 |
| Human-only规则未建立 | 课程治理不满足 | 在检查点1由用户亲自建立，agent只提供建议 |
