# Memory/state design

每run使用独立目录，保存不可变manifest、原始数据及hash、证据、claim、用量事件、验证结果和修订。预算预留与结算采用SQLite事务或等价跨进程原子存储，不用普通内存计数器冒充共享总账。崩溃后的在途预留保留并标unknown，不因重启恢复额度。

业务长期记忆默认关闭；两组实验均从同一空/只读初态启动。checkpoint只恢复同run、相同manifest和策略hash，不复用模型完成缓存。fixture回放使用记录响应，不访问API。

写入者：数据适配器写原始数据和证据；runner写状态；budget写usage；gate写判定；人工入口写审阅。应用agent不能改manifest、原始证据、预算策略或批准记录。

原始业务数据建议保留7天，脱敏元数据30天；课程证据保留至课程结束后90天。到期只提示，不自动删除。原始会话和个人附件私存，公开副本经过脱敏并保留原文hash和脱敏说明。

凭据只保存在仓库外的本机私有文件。API请求通过预配置HTTPS目标；本机relay仅绑定127.0.0.1，使用短期本地token，不记录Authorization或请求原文中的凭据。
